Spectral Engine

Spectral Engine is a set of sound visualizers, for anyone who wants moving pictures to go with music.

It offers twelve visualizers. The MIC button feeds any visualizer from the microphone. The second version can take its sound from a shared band and keep time with it.

Live at spectral-engine.vercel.app

This app is checked every morning by Control Troll.
